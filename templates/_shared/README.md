## Running

Make the scripts executable (first time only):

```bash
chmod +x Allrun Allclean
```

Run the full case:

```bash
./Allrun
```

Or step-by-step:

```bash
blockMesh
{% if geometry_type == "stl_import" -%}
surfaceFeatureExtract
snappyHexMesh -overwrite
{% endif -%}
{% if solver_name == "interFoam" -%}
setFields
{% endif -%}
checkMesh
{{ solver_name }} 2>&1 | tee log.{{ solver_name }}
```
{% if solver_name == "interFoam" %}
> **Note (dam-break / two-phase)**: `system/setFieldsDict` initialises
> `alpha.water = 1` inside the water column box. `./Allrun` calls `setFields`
> automatically between `blockMesh` and `interFoam`.
{% endif %}
## Post-processing

```bash
# Extract convergence residuals

# Visualise in ParaView

# Sample along predefined lines (centreline + cross-section)
postProcess -func sample -time latest   # → postProcessing/sample/

# Extract values at probe points (10 % / 50 % / 90 % of domain length)
postProcess -func probes -time latest   # → postProcessing/probes/
```

`system/sampleDict` extracts velocity, pressure and turbulence fields along a
streamwise centreline and a wall-normal cross-section.  `system/probesDict`
places three probes along the mid-height centreline.
